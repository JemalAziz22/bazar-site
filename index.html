مميزات مصممة لاحتياجات المتجر اليومية

يجمع BAZAR بين السرعة الفائقة للتخزين المحلي والربط السحابي المباشر لخدمة كافة العمليات التجارية.

إدارة المنتجات والمخزون

إضافة وتعديل الأقسام والمنتجات، متابعة الكميات المتبقية، وتلقي تحذيرات عند انخفاض المخزون لمنع البيع فوق المتاح.

نقطة البيع والباركود السريع

إدراج العناصر لسلة البيع بنقرة واحدة أو بمسح الباركود عبر الكاميرا باستخدام تقنيات Google ML Kit وإصدار الفواتير فوراً.

مرونة سعر الصرف والعملات

إمكانية تحديث سعر صرف الدولار مقابل الليرة السورية، وحساب قيم الفواتير والأرباح بالعملتين دون تضارب في التسعير.

المصاريف وتصدير تقارير Excel

تسجيل المصاريف اليومية والثرية، وتوليد تقارير مالية وتصديرها بصيغة ملفات Excel منسقة (Apache POI) مباشرة من الهاتف.

تصفح المتاجر وطلب الزبون

واجهة تتيح للزبون تصفح المتاجر المتاحة عبر مرآة Firestore العامة، اختيار المنتجات، إنشاء الطلبات ومتابعة حالتها.

مركز التوصيل وتتبع الشحنات

واجهة لكباتن التوصيل لمتابعة الطلبات المتاحة، استلام الشحنة، والتحديث الفوري لحالة التوصيل حتى التسليم للزبون.

منظومة مترابطة

مصمم ليخدم الأدوار الثلاثة في السوق

تكامل سلس بين صاحب المتجر والزبون ومركز التوصيل عبر قاعدة بيانات سحابية متناسقة.

01

صاحب المتجر (Store Owner)

تحكم كامل في المخزون، التسعير، نقطة البيع السريعة، الفواتير، متابعة المصاريف والتقارير المالية لتسهيل الإدارة اليومية.

02

الزبون (Customer)

استكشاف المتاجر القريبة، البحث عن المنتجات بالاسم أو الصنف، تجميع سلة المشتريات ومتابعة حالة الطلب خطوة بخطوة.

03

مركز التوصيل (Delivery Center)

لوحة متابعة استلام الطلبات الجاهزة، التوجه للعنوان المطلوب، وتحديث حالة الشحنة فور تسليمها بنجاح.

خطوات عمل سلسة

كيف تسير العمليات في التطبيق؟

مخطط تسلسلي بسيط يوضح تدفق البيانات والعمليات من الإدخال المحلي إلى التسليم النهائي.

1

تهيئة المتجر والمخزون

يضيف صاحب المتجر المنتجات والباركود وسعر الصرف اليومي. يتم حفظ البيانات فوراً في قاعدة بيانات SQLite المحلية.

2

البيع ومسح الباركود

في نقطة البيع POS، يمسح التاجر باركود المنتجات بكاميرا الهاتف عبر ML Kit، أو يطلب الزبون المنتجات من التطبيق.

3

إصدار الفاتورة وخصم الكمية

تُحسب الفاتورة بدقة، وتُخصم الكمية المباعة تلقائياً من المخزون مع رفض البيع في حال عدم كفاية الكمية.

4

المزامنة السحابية والتقارير

تتم مزامنة البيانات في الخلفية عبر WorkManager مع Cloud Firestore، مع إمكانية تصدير تقارير Excel للمصاريف والمبيعات.

للمطورين والمهتمين بالجانب التقني

التعريف التقني والبدائل المعمارية

بنية برمجية معاصرة ومستقرة تجمع بين أحدث مكتبات Android مع الالتزام بأفضل الممارسات.

الواجهات والمعمارية (UI & Architecture)

  • Kotlin 1.9+ & Java 17: اللغة الأساسية للمشروع مع bytecode بنسخة Java 17.
  • Jetpack Compose & Material 3: واجهات مستخدم حديثة 100% وديناميكية مع دعم الوضع الداكن والفاتح.
  • Clean Layered Architecture: فصل الطبقات بين المزايا (features)، البيانات (data)، والنواة (core).
  • Navigation Compose: إدارة التنقل بطريقة آمنة برمجياً ودون الاعتماد على XML Views القديمة.

قواعد البيانات والمزامنة (Data & Sync)

  • SQLite Engine (Offline-First): محرك محلي مخصص لإدارة العمليات بدون اتصال شبكي.
  • Cloud Firestore & Storage: تخزين بيانات المتاجر العامة ومزامنة طلبات الزبائن وصور المنتجات.
  • WorkManager (SyncWorker): مهام خلفية جارية لمزامنة المبيعات عند توفر الاتصال.
  • DataStore Preferences: حفظ تفضيلات المستخدم وإعدادات أسعار الصرف المحلية.

العتاد والذكاء الاصطناعي (Hardware & ML)

  • CameraX Integration: التعامل الكفء مع الكاميرا وإدارة دورة حياتها برمجياً.
  • Google ML Kit Barcode: قراءة وتحليل الباركود أوتوماتيكياً في أجزاء من الثانية.
  • Apache POI (Excel): إنشاء وتنسيق ملفات التقارير (.xlsx) وتخزينها على الهاتف.
  • Coil Image Loader: تحميل الصور وتخزينها مؤقتاً بأداء عالٍ متوافق مع Compose.

مواصفات البناء والنظام (Build Specs)

  • Android SDK Limits: Min SDK 26 (Android 8.0)، Target SDK 34، Compile SDK 35.
  • Gradle Kotlin DSL: إدارة الاعتماديات بملفات Kotlin Script مع Version Catalogs.
  • Firebase Auth Rules: تأمين حماية بيانات الأدوار (Store, Customer, Delivery).
  • Single Module :app: وحدة تطبيق رئيسية تضمن سهولة التطوير والصيانة.
إجابات واستفسارات

الأسئلة الشائعة

إليك الإجابات عن أكثر الأسئلة تكراراً حول كيفية عمل تطبيق BAZAR وآلية التخزين والتصدير.

كيف يعمل التطبيق في حالة عدم توفر الاتصال بالإنترنت (Offline Mode)؟ ▼

يعتمد التطبيق محلياً على محرك SQLite مخصص، مما يتيح لصاحب المتجر إضافة المنتجات، إجراء المبيعات عبر نقطة البيع POS، وإصدار الفواتير وتسجيل المصاريف بشكل كامل وبسرعة فائقة حتى دون وجود شبكة إنترنت. وعند توفر الاتصال، يقوم محرك WorkManager بمزامنة البيانات سحابياً تلقائياً.

كيف يتم التعامل مع سعر صرف الدولار والعملة المحلية؟ ▼

يتيح التطبيق لصاحب المتجر تحديد وتحديث سعر صرف الدولار مقابل الليرة السورية بسهولة من الإعدادات أو الشاشة الرئيسية. يتم توحيد هذا السعر في كافة عمليات البيع والفواتير والتقارير لتفادي أي تضارب بين العملتين.

كيف تعمل تقنية مسح الباركود عبر الكاميرا؟ ▼

يستخدم التطبيق مكتبات Android CameraX مع Google ML Kit Barcode Scanning لقراءة الباركود مباشرة من بث الكاميرا بكسور من الثانية، ثم البحث التلقائي عن المنتج وإضافته لسلة البيع دون الحاجة لماسح باركود خارجي.

هل يمكن تصدير التقارير المالية لملفات Excel؟ ▼

نعم، يدعم BAZAR إنشاء وتنسيق ملفات تقارير Excel المنسقة بصيغة (.xlsx) مباشرة من الهاتف باستخدام مكتبة Apache POI، مما يتيح لك حفظ ومشاركة تقارير المبيعات والمصاريف بسهولة.

كيف تتفاعل واجهة الزبون مع مركز التوصيل؟ ▼

عندما يرسل الزبون طلباً عبر التطبيق، يتم إدراجه في قاعدة بيانات Cloud Firestore. يستطيع مركز التوصيل رؤية الطلبات المتاحة، قبولها، وتحديث حالتها إلى "قيد التوصيل" أو "تم التسليم" مع إشعار الزبون بالحالة الحية.
